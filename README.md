# Tomas Vales — Portfolio

Personal portfolio: a single page in black and white with a loader, smooth scrolling, a custom cursor, magnetic buttons, project previews that follow the cursor, a horizontal-scroll toolbox and full-screen project pages. Available in English, Italian and Spanish.

Built with React, TypeScript, Vite, Tailwind, GSAP (ScrollTrigger) and Lenis.

```bash
npm install
npm run dev     # local server
npm run build   # builds dist/
```

Projects, texts and translations live in `src/content.ts`. Screenshots go in `public/work/`.
Pushing to `main` publishes the site to GitHub Pages.
